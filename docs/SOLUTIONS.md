# 关卡通关顺序

仅用于验证或卡关时参考。坐标按（行，列），从 1 开始。每步等待箭头飞出后再操作。

## 第 1 关：初识方向

(1, 4) → (2, 1) → (2, 3) → (3, 1) → (4, 3) → (3, 2) → (3, 3) → (3, 4) → (1, 2) → (4, 4)

## 第 2 关：交错路径

(1, 1) → (1, 3) → (2, 1) → (2, 2) → (3, 5) → (4, 1) → (5, 1) → (5, 2) → (5, 3) → (1, 4) → (3, 1) → (4, 2) → (4, 3) → (4, 5) → (5, 4) → (3, 3) → (3, 4) → (4, 4) → (5, 5)

## 第 3 关：层层解锁

(1, 1) → (1, 3) → (1, 4) → (1, 6) → (3, 1) → (3, 6) → (4, 1) → (5, 6) → (6, 1) → (6, 4) → (6, 5) → (6, 6) → (1, 5) → (2, 1) → (2, 3) → (2, 6) → (4, 3) → (4, 4) → (5, 1) → (5, 3) → (6, 2) → (6, 3) → (1, 2) → (2, 5) → (3, 4) → (4, 6) → (5, 2) → (2, 2) → (3, 2) → (3, 3)
